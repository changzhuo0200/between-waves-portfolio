两次分析都获得了认可，也成为我进入后续内容工作的起点。后来，分析、选题、文案、视觉与反馈逐渐连成一个持续修改的过程。

01 / BEFORE THE FIRST POST

两次分析，是这段工作的起点

账号不缺产品，也不缺发布数量。更需要补上的，是用户从“看到课程”到“理解自己为什么需要它”之间的证据。

01 · NANJING

南京账号对比分析

对照上海、兰州、苏州、武汉、天津等区域账号，定位重复营销、服务过程不足和内容衔接不自然的问题。

  1. 先说明问题，再介绍课程
  2. 一篇笔记只完成一个主要任务
  3. 用真实教学过程建立信任
02 · JIANGSU

江苏账号运营分析

继续区分学生、家长、产品与教师内容各自承担的任务，并观察栏目能否形成连续阅读。

栏目是一种系统化、专业化的呈现，也是对用户下一次阅读的承诺。
02 / WORKFLOW

把平台逻辑带进内容制作

从人群和问题出发，决定关键词、封面和内页；发布后再回看内容表现，进入下一次修改。

  1. 01人群与问题
  2. 02关键词
  3. 03封面
  4. 04内页
  5. 05发布
  6. 06查看表现
  7. 07下一版

01确认目标人群、使用场景和最需要解决的问题。

VISUAL PRODUCTION

视觉制作边界

我负责内容拆分、页面重点、方案筛选、排版修改和最终交付。AI 主要用于基础素材与初步方案。

  • 10%模板参考
  • 10%优化方向
  • 50%AI 辅助
  • 30%个人构思与手工排版
03 / NOTES IN PRACTICE

从分析进入笔记生产

CASE 01

高中数理化一对一

封面先让用户看懂课程和师资，第二页再用真实学习场景、板书和练习素材说明一对一怎样进入学习过程。

  • 这是什么课程
  • 课程怎样开展
  • 用户下一步可以做什么
CASE 02

期中弱科提升

这一组先让用户理解“弱科为什么难提升”，再把方法拆成课前诊断、课中训练和课后巩固。

问题先被看懂，课程才知道应该出现在哪里。
CASE 03 · REBUILT

选题 / 主题小高考生物

第一轮完成度尚可，但带教反馈是“不够营销、表达偏软”。封面缺少问题钩子，也没有突出产品和课程。需求重新明确后，我重设每一页的任务，制作了三页连续内容。

EARLY DIRECTION

最初方案 · 手工排版

FINAL SET

04 / CURRENT SIGNAL

内容开始带来变化

据带教反馈，高中数理化及数篇非营销笔记上线后，南京账号在引导用户咨询和留下联系方式方面有所改善。

05 / LINER NOTES

目前留下的四个判断

  1. 01先明确笔记需求：写给谁、解决什么、要突出哪门课程。
  2. 02一页只讲一件事，下一页自然接上。
  3. 03用真实过程和具体证据代替抽象卖点。
  4. 04结构不对，就回到需求重新开始。
